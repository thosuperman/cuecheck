# Security

CueCheck reads explicitly named local files without elevated privileges. It has no network client, updater, telemetry or plug-in loader. Its output contains local paths but not subtitle text; review paths before sharing a report.

For a suspected security issue, **do not post sensitive details publicly**. Use “Report a vulnerability” on the [Security tab](https://github.com/thosuperman/cuecheck/security) if available. Otherwise open an issue asking the maintainer for a private reporting channel, without describing the vulnerability. Ordinary caption-format bugs belong in GitHub Issues. Fixes target the latest release.
